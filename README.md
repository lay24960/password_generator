# Random Password Generator 
**Автор:** Терпан Александр
**Дата создания:** 25 мая 2026

## Описание

**Random Password Generator** - графическое приложение для генерации случайных паролей с возможностью настройки параметров, сохранением истории и копированием в буфер обмена.

### Функциональность

- ✅ Генерация паролей с выбором:
  - Строчные буквы (a-z)
  - Заглавные буквы (A-Z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&*)
- ✅ Ползунок для выбора длины пароля (от 4 до 32 символов)
- ✅ Копирование пароля в буфер обмена
- ✅ Автоматическое сохранение истории в JSON
- ✅ Таблица истории с датой и временем создания
- ✅ Очистка истории
- ✅ Проверка корректности ввода
